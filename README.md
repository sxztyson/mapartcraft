# MapartCraft Reverse

MapartCraft with an integrated browser-based NBT/ZIP to Minecraft map-image reconstruction mode.

Live site: https://sxztyson.github.io/mapartcraft/

Based on [mike2b2t/mapartcraft](https://github.com/mike2b2t/mapartcraft), distributed under GPL-3.0. The editable source and reverse-decoder documentation are maintained separately from this compiled GitHub Pages branch.
